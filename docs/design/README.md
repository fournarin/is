# The second-generation screens: design record

These files are the working record of the screen redesign that followed the first
outside trial on the old screens (17 November 2026). They are kept here because the
report's chapter 6 cites them; the built result is in `web/` and in
[ADR-133](../adr/0133-the-screens-are-rebuilt-on-one-design-system.md) to
[ADR-144](../adr/0144-end-to-end-flows-and-an-accessibility-scan-in-the-repo.md).

| File | What it is |
|---|---|
| `REQUIREMENTS.md` | the 107 screen requirements, each with a pass/fail check (in Thai) |
| `TRACEABILITY.md` | requirement → screen → evidence, with the status of each one on 18 November 2026 |
| `review/` | the reviewers' notes, one file per gate and role; each reviewer was a fresh AI agent that had not built what it reviewed, and the owner decided every gate |
| `research/patterns.md` | the patterns the requirements draw on (lockout/tagout, Thai typography, mobile work orders) |

Paths inside these notes (`design/...`, `/Users/...`) point to the working folder the
redesign was done in, outside this repository. Screenshots and the outside tester's
questionnaire are not published here; the tester's questionnaire stays with the owner.

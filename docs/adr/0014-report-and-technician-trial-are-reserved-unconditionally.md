# ADR-014: Reserve time for the report and the technician trial in every case

## Context

The plan had phase 3 branching on whether data arrived, with "write the report
properly" and "test with a real technician" living on only one branch. But the
report is the only artefact the advisor named as producing a grade, and the
project's stated goal requires a technician to be able to use the system.

## Decision

Compress phase 3 into weeks 10-12 and reserve weeks 13-14 for writing and
handover in every case. Finding at least one technician to try the system belongs
to both branches; if none can be found at the plant, use somebody outside it.

## Reasons

What is graded, and what the project exists for, should not depend on an event we
do not control. Leaving the report to the branch where the technical work failed
means the case where everything goes well is the case with no time to write it
up, which is backwards.

## Consequences

Technical work has twelve weeks, not fourteen. Scope must be cut to fit twelve
from the start, and week 12 is a hard stop on new features regardless of what is
unfinished.
